# RSA utility

Goal: Generate RSA key pairs and encrypt/decrypt UTF-8 strings for the login flow.
Planning trigger: Security-sensitive cryptographic contract.
Acceptance: Standard RSA-2048 OAEP SHA-256/MGF1 SHA-256, SPKI/PKCS8 Base64 keys, explicit byte limit, no plaintext logging or private-key persistence changes.
Verification: Round trip, random ciphertext, wrong key, corrupted ciphertext and size limits; compile/run with JDK when available. Maven checks if available. Report unverified browser interoperability.
